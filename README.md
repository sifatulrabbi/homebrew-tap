# Sifatulrabbi Tap

## How do I install these formulae?

`brew install sifatulrabbi/tap/<formula>`

Or `brew tap sifatulrabbi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sifatulrabbi/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
